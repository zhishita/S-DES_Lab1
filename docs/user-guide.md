## 环境与启动

需要 Python 3.10+，以及 Chrome、Edge、Firefox 等现代浏览器。Windows、macOS、Linux 均可运行。下载并解压仓库，在包含 `sdes` 和 `web` 的文件夹打开终端，运行 `python -m sdes.webapp --open`。如果 `python` 未安装或不在 PATH，需要先安装 Python。默认访问 `http://127.0.0.1:8765`；端口占用时运行 `python -m sdes.webapp --port 8768 --open`。服务仅监听本机地址，不需要联网。

## 分组实验

1. 输入分组 `10010111` 和主密钥 `1010000010`。
2. 点击“加密分组”，结果为 `00111000`，十六进制 `38`。
3. 点击“结果作为输入”，再点击“解密分组”，结果还原为 `10010111`。
4. K1 为 `10100100`，K2 为 `01000011`。展开“轮函数内部状态”，查看 EP、异或、S 盒输出及 P4。

输入必须严格为 8 位分组和 10 位密钥；不会静默补零或忽略空格。错误提示位于页面底部。解密按 K2、K1 顺序执行两轮。

## 字符串实验

选择 ASCII 编码，输入 `Hello, S-DES!`，密钥仍为 `1010000010`。点击“加密字符串”，输出 HEX `C4F80D0D2F99624F365F504F29`，共 13 字节。点击“结果作为输入”再点击“解密 HEX”，还原原文。

ASCII 模式接受码点 0～127；包含中文时会明确报错。可选择 UTF-8 扩展，以字节分组处理中文与 emoji。密文可能含控制字符，直接显示容易丢失内容；界面同时提供十六进制、分组二进制和转义字节串。HEX 解密支持字节之间的空格，不支持奇数位或非十六进制字符。空字符串合法，无需填充；一个明文字节恰好产生一个密文字节。解密时必须使用相同密钥与编码。

## 密钥搜索

每行填写“8 位明文 空格 8 位密文”。例如：

```text
10010111 00111000
```

点击“搜索全部密钥”，完整检查 `0000000000` 到 `1111111111`，输出所有满足已知对的候选，显示 UTC 起止时间、实际毫秒数与每 64 个密钥的采样。该样例有 3 个候选：`0111001010`、`1010000010`、`1011001010`。

多行已知对会取条件交集，不会只返回第一个匹配密钥。无结果意味着输入条件没有共同满足的密钥。由于搜索很快，进度条显示最终完成状态；实测过程可查看时间戳列表和仓库的慢速回放动图。多线程是可选项，本项目采用单线程完整搜索。

## 碰撞探索

输入固定明文 `00000000`，点击“枚举 1024 个密钥”。结果为 240 种不同密文、224 个碰撞桶、最大桶 12 个密钥、16 个单候选桶。表格列出全部碰撞桶及其中所有密钥；滚动表格查看完整结果。

## 复现实验

普通测试运行 `python -m unittest discover -s tests -v`。全空间跨语言验证需额外安装 Node.js 18+，再运行 `python -m tests.run_experiments`。结果写入 `results`，会覆盖原有实验结果文件。动图重建需 Pillow，方法见 README。界面启动无需 Node.js 或 Pillow。
